# 🏹 射箭遊戲優化筆記

## ✨ 遊戲性改進

- **修正計分系統**：中心圈 10 分，越外圍分數越低
- **箭矢限制**：10 支箭的挑戰制
- **連擊系統**：連續命中靶心可獲得額外獎勵
- **最高分記錄**：使用 `localStorage` 保存分數
